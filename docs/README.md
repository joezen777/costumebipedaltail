## Where the files are

| Path | What |
|---|---|
| `tailsim/` | MuJoCo physics package (parameters, model builder, simulator, metrics, plots, linear modes, mass budget) |
| `tests/` | `test_physics.py` (8 physics validation tests), `test_cad.py` (OpenSCAD ⇄ Python spec, printability) |
| `experiments/` | `sweep.py` (tuning), `run_suite.py` (study + media), `make_tables.py` (docs tables) |
| `cad/geometry.py` | Single dimensional spec shared by physics, OpenSCAD test and FreeCAD |
| `cad/openscad/suit_tail.scad` | Parametric OpenSCAD model (README §20 modules and PART views, plus print-oriented parts) |
| `cad/freecad/build_tail.py` | Parametric FreeCAD model (`createVertebra(index, parameters)`), writes FCStd + STEP |
| `cad/freecad/output/` | `suit_tail_barney.FCStd/.step` |
| `cad/openscad/suit_tail_barney.scad`, `cad/variants/barney.json` | Barney variant parameters (generated by `cad/make_variant.py` from the simulated design) |
| `cad/stl/barney/` | **Print-ready STLs for the Barney tail** (6 joints); `cad/stl/parts_barney.json` = sizes, volumes, masses |
| `cad/add_support_columns.py` | Overhang checker (optionally writes break-away columns). The bodies and hip mount are self-supporting by design |
| `cad/stl/replica_1to8_resin/`, `cad/openscad/mini_kit.scad` | 1:8 snap-together resin kit (twine + orthodontic elastics); `cad/export_replica.py` |
| `cad/stl/figurine_1to8_resin/`, `cad/openscad/figurine_1to8.scad` | 1:8 low-poly protogen-head figurine with a T-slot for the kit's plate at 14 levels; `cad/export_figurine.py`, `cad/render_figurine.py` |
| `results/figures/`, `results/animations/`, `results/cad_renders_barney/`, `results/pose_renders/`, `results/simulated_photos/` | Plots, animations, CAD views, pose renders, photos |
| `results/data/` | Metrics JSON, per-timestep CSVs (`csv/`), mass budget |
